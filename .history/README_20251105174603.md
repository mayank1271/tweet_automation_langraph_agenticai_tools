# 🚀 Selenium + Chrome Saved Login (Windows Setup Guide)

This setup allows Selenium to use a **saved Chrome login**, so you do **not** need to sign in every time.  
We will attach Selenium to a Chrome session that is already logged in.

---

## ✅ 1) Install Requirements

Open CMD in your project folder:

```bash
pip install selenium webdriver-manager
````

---

2) Create a Chrome Profile Folder

Create a new empty folder where Chrome will store cookies & login:

```
C:\SeleniumProfile
```

> This must be a **new folder**, not your default Chrome profile.

---

3) Start Chrome in Debug Mode (Important)

**Close ALL Chrome windows first**, then run this command in **CMD**:

```bat
"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\SeleniumProfile"
```

If Chrome is installed in the 32-bit path, use this:

```bat
"C:\Program Files (x86)\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\SeleniumProfile"
```

Chrome will open →
**Log in to X.com** only once.
Your login will now stay saved in this profile.

---

4) now C:\Users\mayank manjhi\Downloads\(1)lang,rag,ai\agenticai\tools\utils.py file for connecting the chrome

now run modelrunpipeline.py

Workflow Summary

| Step # | Action                                |
| ------ | ------------------------------------- |
| 1      | Run Chrome with debug mode (Step 3)   |
| 2      | Login to X.com (only first time)      |
| 3      | Run Python (Step 4)                   |
| 4      | Selenium attaches to logged-in Chrome |

---

Common Issues & Fixes

| Problem                                | Reason                             | Solution                                                 |
| -------------------------------------- | ---------------------------------- | -------------------------------------------------------- |
| Chrome opens normally (not debug mode) | Chrome was already running         | Close **all** Chrome windows and run Step 3 again        |
| Login did not save                     | Chrome wasn't started with profile | Make sure Step 3 is done before login                    |
| Port conflict                          | 9222 in use                        | Change both Chrome & Python to another port (e.g., 9223) |

---
Done!

Your Selenium now works with **real Chrome** + **saved login** + **no re-login needed**.
